# Karaoke Tax Planner 2026

Static HTML website deployable on Vercel without dependencies.

## Deployment

1. Import a GitHub repository containing `index.html` and `vercel.json` into Vercel, select Framework Preset: Other, then Deploy.
2. Alternatively use the Vercel CLI from this folder: `npx vercel --prod` (sign in when prompted).

This site estimates taxes and is not a substitute for an accountant's review of applicable law or filings.
